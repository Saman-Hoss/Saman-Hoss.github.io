This project develops data-parsimonious models for dengue risk assessment and outbreak forecasting. The main goal is to create modeling frameworks that are not site-specific and can be adapted across different geographic regions using limited epidemiological information.

The project focuses on reduced epidemic models, incidence-cumulative relationships, and forecasting methods that can support outbreak prediction when detailed local transmission data are unavailable. This framework is designed to be flexible, interpretable, and practical for public-health applications.

Methods and tools: epidemic forecasting, incidence-cumulative curves, reduced epidemic models, stochastic simulation, mathematical modeling, Python.

Related work: A two-parameter, minimal-data model to predict dengue cases: the 2022–2023 outbreak in Florida, USA.
